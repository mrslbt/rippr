# Chrome Web Store Listing

## Name
rippr — YouTube Transcript Ripper

## Short Description (132 chars max)
Rip YouTube transcripts to clean text files. Built for RAG, LLM workflows, and AI research. One click. Multiple formats.

## Detailed Description

rippr extracts transcripts from any YouTube video and saves them as clean, structured files — perfect for feeding into ChatGPT, Claude, RAG pipelines, or any LLM workflow.

HOW IT WORKS
1. Go to any YouTube video with captions
2. Click the rippr button on the video page (or use the popup)
3. Choose your format and download

OUTPUT FORMATS
- RAG (.txt) — Single continuous text block, optimized for chunking and embedding
- Structured (.json) — Timestamped segments with full metadata
- Readable (.md) — Clean markdown with headers and formatting

FEATURES
- In-page button directly on YouTube watch pages
- Popup interface — paste any YouTube URL
- Multi-language support with language selector
- Auto-generated caption detection
- Optional timestamps
- Multiple fallback strategies for reliable extraction

BUILT FOR AI WORKFLOWS
rippr outputs are designed to drop straight into your AI pipeline. The RAG format joins all text into a single block for clean chunking. The JSON format includes timestamps, duration, and metadata for structured processing.

PRIVACY
rippr runs entirely in your browser. No data is collected, stored, or sent to any external server. Transcripts are downloaded directly to your machine.
